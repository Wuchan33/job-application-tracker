# Privacy Policy

Job Application Tracker is a self-hosted application that runs locally on the user's machine.

- The app requests read-only access to Gmail (`gmail.readonly`) to identify job application emails.
- Email data is stored only in the user's local database. It is not sent to the author or any third-party server,
  except to the LLM provider configured by the user (e.g. Google Gemini) for classification.
- No data is sold, shared or used for advertising.
- Access can be revoked at any time at https://myaccount.google.com/permissions.

Questions or concerns: https://github.com/wuchan33/job-application-tracker/issues
